Как работает шкала
граница входит в интервал не входит уходит в бесконечность оценка вне 0–100 % смена направления оценки
1Интервалы идут подряд
Первый начинается с −∞, последний идёт до +∞. Начало каждого интервала подставляется из конца предыдущего — вводите только правую границу.
−∞…70…100…+∞
2Оценка меняется в одну сторону
С ростом значения КПЭ оценка только растёт или только снижается. Направление определяется само.
✓0 → 50 → 100растёт — верно
✓100 → 50 → 0снижается — верно
✓0 → 0 → 100повтор допустим — верно
✗100 → 0 → 50сначала снизилась, потом выросла — ошибка
3Оценка от 0 до 100 %
Для «Оценка = значению» весь интервал должен лежать в пределах 0–100, поэтому у первого и последнего интервала такой вариант недоступен. Не доступен он и при абсолютной формуле, если единица измерения не «%».
✓0 % → 50 % → 100 %в пределах 0–100 % — верно
✗50 % → 100 % → 120 %больше 100 % — ошибка
✗-10 % → 0 % → 50 %меньше 0 % — ошибка
Новый интервал встанет перед последним (до +∞)
